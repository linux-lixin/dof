# 登录器与客户端

源码和构建入口见 [clients/launcher](../../clients/launcher/README.md)，原使用图文见 [登录器使用说明](usage.md)。
此目录的 `images/` 只放文档配图，参与 WPF 编译的图片继续保留在登录器项目中。

配置完整流程见 [客户端、登录器与更新发布](../centos/deployment.md#13-在-windows-编译登录器并配置客户端)，
该部分后台设置也适用于 Ubuntu 游戏镜像。服务器端 `.env` 的 `PUBLIC_IP` 不会自动填写所有后台下发配置。

部署顺序是：游戏与后台就绪 → 初始化管理员 → 同步游戏公钥 → 配置玩家可达地址 → 配置客户端包和版本记录 →
在 Windows 实机验证注册、登录与下载更新。私钥仅留后台，玩家端不应拿到服务器数据库凭据。

此次整理保留登录器的项目名称、资源路径、协议和业务代码；未重新进行 Windows 实机进游戏验收。
